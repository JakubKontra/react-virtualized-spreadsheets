# Your first spreadsheet

This is the same component used by the live basic example. It creates a complete in-memory source, wraps it in a view and gives the resulting store to the UI renderer.

## 1. Add the styles

After [installing the packages](installation.md) and configuring Tailwind 4, import an application stylesheet:

```css title="style.css"
@import 'tailwindcss';
@import '@sheet/ui/styles.css';
```

## 4. Render the spreadsheet

<CodeBlock language="tsx" title="basic.tsx">
  {basic}
</CodeBlock>

Mount the component in your app:

```tsx title="main.tsx"
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import Basic from './basic';
import './style.css';

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <Basic />
  </StrictMode>,
);
```

The host HTML needs `<div id="root"></div>` and a module script pointing to `main.tsx`. The repository's `apps/docs-examples` contains that complete Vite app.
