Edit A1 in Warehouse A. Its B1 recalculates while Warehouse B stays unchanged. Each instance has its own selection, history and menu scope. **Reset data** resets both instances.

<LiveExample name="independent" title="Two independently editable spreadsheets" />

These inputs live only in memory. Resetting or leaving the page discards edits; no API or account is required. On narrow screens, scroll inside the grid or open the example full screen.
